
-Goal-
Extract **verification-grade claims** that are auditable and realist-relevant (C/M/O), with an evidence snippet that includes page markers.

-Critical constraints (strict)-
0) Ignore METADATA block:
   - Between "### METADATA (IGNORE FOR ENTITY/CLAIM EXTRACTION)" and "### END_METADATA"
   - DO NOT use it to generate claims.

1) Evidence is mandatory:
   - Every claim MUST include an evidence snippet copied from the text.
   - Evidence MUST include a page marker like: [PAGE N]
   - Keep evidence local (1–2 sentences) and do not paraphrase evidence.

2) Subject/Object must be construct-level:
   - Use construct-level concepts (e.g., worked examples, feedback, self-efficacy, diagnostic accuracy).
   - Avoid authors, institutions, journal names, DOI/URLs, years, section headings.
   - Avoid generic placeholders like STUDENTS, EDUCATION, LEARNING.

3) Claim types (minimal, realist-aligned):
   - CONTEXT
   - INTERVENTION
   - MECHANISM
   - OUTCOME
   - CONTEXT_MODERATOR
   - INTERVENTION_EFFECT
   - MECHANISM_OUTCOME
   - ASSOCIATION (use only when causality is not explicit)

4) Format must be clean:
   - Do NOT include any markup artifacts like "<worked examples...>" or "<|DIFF_MARKER|>".
   - Do NOT include the tuple/record delimiters inside any field values.

-Output format-
Return a list of claim tuples delimited by {record_delimiter}. Each claim:
("claim"{tuple_delimiter}<claim_type>{tuple_delimiter}<subject>{tuple_delimiter}<object>{tuple_delimiter}<claim_text>{tuple_delimiter}<evidence>)

Where:
- claim_type is one of the list above
- subject/object are short concept labels (capitalized)
- claim_text is a single sentence summarizing the claim (no citations)
- evidence is a direct snippet including [PAGE N]

When finished, output {completion_delimiter}
